# Evaluator quick start

This confidential senior-evaluation project uses synthetic onboarding data. It is not a production HR deployment.

## Demonstration order

1. HR publishes a synthetic template, creates and activates a case.
2. Manager records typed first-week preparation evidence.
3. Employee explores permitted onboarding tasks and policy acknowledgement.
4. IT demonstrates clearly labeled simulated provisioning with persisted audit.
5. HR reviews the portfolio and evidence-based closeout readiness.

The signed-in application's Evaluation walkthrough guides each role without making workflow changes itself.

# M1 — Identity, authorization and audit foundation

Decision scope: M1 only, no real employee documents, no externally provisioned services.

- Custom email-unique Django user from first migration, single active organization membership with one of EMPLOYEE, HR, IT, MANAGER; roles are never taken from client JSON.
- Server-side session cookies, CSRF on every unsafe request, 30-minute idle / 8-hour maximum session policy, Argon2 password hashing and bounded login throttles.
- No public registration. HR must be assigned to an employee's case to issue synthetic invitation / employee reset. Tokens are one-time hashed DB records (24h invite, 1h reset). Delivery is a restricted issuer response in M1, **not** a claim of sending email.
- OnboardingCase/CaseAssignment are an M1 access-control shell only. M2 owns actual case/task activation and transitions.
- HR reassignment of IT/Manager is one guarded serialized transaction; HR-to-HR requires the explicit coordinate_ownership capability. Case authorization is rechecked after lock and again on replay.
- Audit append occurs inside the case transaction via a SECURITY DEFINER PostgreSQL function; row locks ensure ordered hash chaining. Trigger prevents UPDATE/DELETE; runtime-like restricted roles cannot UPDATE/DELETE/TRUNCATE through PostgreSQL privileges. Privileged schema/migration owner retains TRUNCATE for test resets and maintenance. DBA/operator compromise is **not** covered by tamper-resistance claims.
- Retries use one receipt per (actor, route, key) with normalized payload hash. Conflicting payloads reject, original business effects do not replay.
- No application UI is labeled as onboarding ready. The M1 UI supports sign-in/out and authorized case previews only.

M1 gates: real PostgreSQL migration/constraint tests, CSRF/session tests, cross-role isolation, unauthorized write attempts, one-use credentials, audit-grant and rollback tests, two-session concurrent idempotency/conflict checks, execution of audit append under a restricted test role, and regression of M0 crash recovery.

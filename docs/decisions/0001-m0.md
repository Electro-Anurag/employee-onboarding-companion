# ADR 0001 — Foundation feasibility branch

Status: candidate, under M0 qualification. Governing architecture: Astra handoff v1.0.

- No business features, third-party accounts, production deployment, or source sharing.
- Django and Procrastinate use **one PostgreSQL transaction** for domain, audit and queued work.
- `backend/jobs/atomic.py` is the single queue insertion boundary. Unqualified `task.defer()` calls outside the domain transaction are forbidden for business follow-ups.
- At-least-once worker delivery is expected. `FoundationEffect` and a unique audit event prove idempotent domain effects.
- Forced postcommit worker exit exists solely for local/CI crash testing, and is not exposed over HTTP.
- This foundation probe is disposable M0 scaffolding, **not** the final product's `OnboardingCase` or audit schema.
- M0 is incomplete until packages are locked, PostgreSQL and worker tests pass, DB grant feasibility is proven, and built React assets are served by Django on the same origin.

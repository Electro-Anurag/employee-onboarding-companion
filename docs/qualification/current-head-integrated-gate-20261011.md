# Completion-branch integrated qualification gate

Source: `.github/workflows/eoc-current-head-integration.yml`.

Triggers once on changes to its own workflow file or by manual dispatch,
exclusively on the private Ubuntu ARM64 self-hosted runner with Docker.
A single disposable PostgreSQL service qualifies locked Python/Node versions,
forward migration from empty, all current-source Python regressions, all
React tests/build, compiled WhiteNoise assets, and a real Chromium four-role
journey against the same origin and real session/CSRF with synthetic accounts.

A PASS is qualified **only at the exact workflow run's GitHub SHA** and
**only for this subset**. A green result does not evidence a populated older
database migration, real S3/ClamAV scan interruption, durable worker
kill/restart, semantic relevance or a live provider, hosted J01–J05,
production backup or release security signoff. A FAIL is retained and
fixed, never softened to make the runner appear green.

The runner may be offline. A queued run is neither PASS nor FAIL.
No GitHub-hosted fallback, secrets, third-party API call or paid deployment.

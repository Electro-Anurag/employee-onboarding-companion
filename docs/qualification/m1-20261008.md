## Corrective findings

Initial test runs found duplicate Django app configuration and an unconditional audit TRUNCATE trigger blocking privileged test-database isolation. Both were corrected. UPDATE/DELETE mutation protection remains at the audit table, and restricted application-like roles are denied direct TRUNCATE. Authentication UI now refreshes the rotated CSRF token after login and confirms logout succeeded before changing visible state.

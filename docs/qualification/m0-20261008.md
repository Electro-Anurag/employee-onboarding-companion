## Architecture correction during M0

The initial integration attempt used Procrastinate's default `DjangoConnector` to defer a job with an external psycopg connection. The three atomic tests failed: `DjangoConnector does not support external connections` (run `37749599912`). This was corrected by using an enqueue-only `SyncPsycopgConnector` with the original Django psycopg connection. Procrastinate's Django integration remains responsible for worker execution and migrations. The corrected path passed commit/rollback tests and the real crash-recovery drill.
